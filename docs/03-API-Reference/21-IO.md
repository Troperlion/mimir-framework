# `Mimir.IO`

API d'I/O exposée par le runtime Lua Mímir 3.1.

Source : `src/scriptings/Lua/luaScripting/LuaScripting.cpp` et
`LuaScriptingTokenizerDataset.cpp`.

## Lecture d'image RGB

```lua
Mimir.IO.read_image_rgb_u8(path, target_w?, target_h?)
    -> { image = integer[], width = integer, height = integer, channels = 3 }
    | (nil, err)
```

Le binding charge une image avec `stb_image`, force trois canaux RGB puis la
redimensionne en bicubique. `target_w` et `target_h` valent `256` par défaut et
doivent être strictement positifs.

L'alias camelCase `Mimir.IO.readImageRGBU8` possède exactement le même contrat.
Il n'existe pas d'alias global `readImageRGBU8`.

```lua
local decoded, err = Mimir.IO.read_image_rgb_u8("image.png", 128, 128)
assert(decoded, err)

print(decoded.width, decoded.height, decoded.channels)
local normalized = {}
for i, value in ipairs(decoded.image) do
  normalized[i] = value / 255.0
end

local output, forward_err = Mimir.Model.forward({ __input__ = normalized }, false)
assert(output, forward_err)
```

## Contrôle des logs standard

```lua
Mimir.IO.suppress_stdout_logs()          -> boolean
Mimir.IO.suppress_stdout_logs(enabled)   -> previous, current
```

Le getter retourne l'état courant. Le setter retourne l'ancien et le nouvel
état. `Mimir.IO.suppressStdoutLogs` est l'alias camelCase.

## Mapping C++

| Appel Lua | Binding C++ |
| --- | --- |
| `read_image_rgb_u8`, `readImageRGBU8` | `LuaScripting::lua_readImageRGBU8` |
| `suppress_stdout_logs`, `suppressStdoutLogs` | `LuaScripting::lua_setStdoutLogSuppressed` |
