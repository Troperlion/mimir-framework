# Diagrammes

Ce dossier contient les diagrammes SVG et les exports Mermaid utilisés par la
documentation Mímir. Les pages Markdown les référencent directement afin
qu'ils restent consultables sans générateur de site.

Lorsqu'un diagramme est modifié, vérifiez que ses libellés correspondent au
code actuel, que les chemins cités existent et que le rendu reste lisible en
thème clair comme en thème sombre.

Revenez à l'[index de la documentation](../00-INDEX.md) pour parcourir les
chapitres associés.
